# AI-Powered Phishing URL Detection Using Machine Learning with Explainable AI

An AI-powered cybersecurity system that detects and classifies malicious phishing URLs using Machine Learning techniques and Explainable Artificial Intelligence (XAI).

The project aims to identify suspicious and fraudulent URLs by analyzing various URL-based features and applying machine learning algorithms to distinguish between legitimate and phishing websites.

Explainable AI techniques are incorporated to provide insights into the model's predictions, helping users understand why a particular URL is classified as phishing or legitimate.

### Key Features

- **URL Analysis:** Analyzes URLs to identify suspicious patterns and characteristics.
- **Feature Extraction:** Extracts important URL-based features such as URL length, domain information, special characters, and other relevant indicators.
- **Machine Learning Classification:** Uses machine learning algorithms to classify URLs as phishing or legitimate.
- **Phishing Detection:** Identifies potentially malicious URLs to improve cybersecurity awareness.
- **Explainable AI:** Provides explanations for the model's predictions using feature importance and explainability techniques.
- **Prediction Results:** Displays whether a given URL is classified as phishing or legitimate.
- **Model Evaluation:** Evaluates performance using metrics such as accuracy, precision, recall, F1-score, and confusion matrix.

### Explainable AI (XAI)

Explainable AI is used to understand the decision-making process of the trained machine learning model.

It helps identify which URL features contribute most to phishing detection and provides transparency in the classification results.

### Project Objective

The main objective of this project is to develop an intelligent phishing URL detection system that can automatically identify potentially harmful URLs using machine learning while providing understandable explanations for its predictions.
